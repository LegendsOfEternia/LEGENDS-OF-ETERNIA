# LEGENDS OF ETERNIA — Godot starter

This is a small **starting project**, not a finished MMORPG and not an Android APK.

## Contents
- `project.godot` — Godot 4 project settings
- `scenes/main.tscn` — main scene
- `scripts/main.gd` — initial menu, class selection, HU/EN toggle

## Open
1. Install/open Godot 4.
2. Choose **Import**.
3. Select this folder's `project.godot`.
4. Open the project and press **F5** to run.

## Important
This starter is only a local interface demonstration. It does not yet contain online accounts, servers, multiplayer, 3D characters, combat, items, payments, or Android APK export setup. Those systems need to be developed and tested separately.
